Featured Project

Apex Doctor — VS Code Extension

An open-source (MIT) TypeScript extension that turns raw Salesforce Apex debug logs into structured, actionable diagnostics. Sole architect, developer, and maintainer across 14+ releases.

2k+ Downloads MIT License 14+ Releases VS Code Marketplace · Open VSX

Adopted by engineering teams internally at Tarana, cutting Apex debug-log triage from ~30 minutes of manual log reading down to seconds. Built as a local, deterministic analysis engine — no API calls required for core diagnostics.

  • Governor-limit parsing, SOQL-in-loop & full-table-scan detection, order-of-execution reconstruction, trigger-order visualization, and an async (@future / Queueable / Batch) tracer.
  • A CPU & heap profiler with self-time attribution (Chrome DevTools–style) that pinpoints the exact method and SOQL query consuming runtime and memory.
  • AI root-cause analysis across five providers (OpenRouter, Anthropic, OpenAI, Google Gemini, Salesforce Einstein Trust Layer) — sending only a distilled, PII-safe summary, with API keys stored in encrypted SecretStorage.
  • Live log streaming, trace-flag management, SOQL Query Plan analysis, in-editor test-coverage overlays, natural-language log querying, and one-click "Suggest Fix" refactors with diff preview — built on the Salesforce CLI & Tooling API.
